# Agent Skills Catalog — Good-to-Have List

A curated catalog of **60 agent skills** worth having — what each one does, who made it, and where to get it.

**Live page:** https://forethinq.github.io/Skills-Catalog/

## What's inside

- **Standalone GitHub repos** — Taste Skill, Open Design, Ponytail
- **Design & UI** — Tailwind Design System, UI/UX Pro Max, shadcn/ui, Emil Kowalski's design skills, Figma, Awwwards-quality sites, and more
- **React & Frontend Engineering** — Vercel React Best Practices, View Transitions, Remotion, React Native
- **Backend, Auth, Deploy & Security** — Better Auth, Cloudflare Deploy, Cloudflare Agents SDK, Varlock
- **Marketing, Content & Social** — Copywriting, Content Strategy, Marketing Ideas, Launch Strategy, Humanizer
- **SEO & Analytics** — Programmatic SEO, SEO Audit, Claude SEO, GEO Optimizer, Analytics Tracking
- **Documents & Office** — PDF, PPTX, DOCX, XLSX, Doc Co-Authoring
- **Planning, Workflow & Meta-Skills** — Writing/Executing Plans, Skill Creator, Find Skills, MCP Builder, Web App Testing

The live page has a search box — open it and filter by name, author, or topic.

## About this repo

- `index.html` is the whole catalog: one self-contained file, no build step, works offline.
- Sources: [AgenticSkills.io](https://agenticskills.io/skills) skill pages and the GitHub repos listed, collected 5 Nov 2026.
- The page is published with GitHub Pages from this repository.
